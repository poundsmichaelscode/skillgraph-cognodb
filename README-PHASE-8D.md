# Phase 8D — Graph Person Selector

Adds a responsive starting-person selector to the graph explorer. Selecting a person loads their graph through the existing Express API. Reset returns to the currently selected person's initial graph.

## Merge

```bash
cp -R /path/to/extracted/phase8d/. .
npx prettier --write apps/web README-PHASE-8D.md
npm run typecheck
npm run lint
npm run build
```
