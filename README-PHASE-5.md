# SkillGraph Phase 5

This package adds the layered catalog API.

Install the additional dependency:

```bash
npm install express-rate-limit --workspace=@skillgraph/api
```

Copy the `apps` directory into the repository while preserving paths. `app.ts` replaces the existing API application file.

Run:

```bash
npm run format
npm run typecheck
npm run lint
npm run build
npm run dev:api
```
